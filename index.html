How to convert an Excel column to a comma separated list

  1. Select the cells in Excel or Google Sheets and copy them (Ctrl+C or Cmd+C).
  2. Paste them into the box above. Each cell becomes one item.
  3. Pick your separator, and add quotes if you need them.
  4. Click Copy and paste the result where you need it.

Example: build an SQL IN list

Paste three values, choose single quotes and tick Wrap in parentheses:

apple
banana
cherry

You get:

('apple','banana','cherry')

Which you can use directly in a query:

SELECT * FROM products WHERE name IN ('apple','banana','cherry');

For numbers or IDs, set quotes to None. Apostrophes inside a value are escaped by doubling them, so O'Brien becomes 'O''Brien', which is what SQL expects.

Frequently asked questions

How do I convert an Excel column to a comma separated list?

Copy the cells in Excel, paste them into the input box on this page, and the comma separated list appears instantly. Click Copy to put it on your clipboard.

How do I make a list for an SQL IN clause?

Choose single quotes for text values (or no quotes for numbers) and tick Wrap in parentheses. You can paste the result straight after IN.

Can I remove duplicates and empty lines?

Yes. Tick Remove duplicates and Remove empty lines. The first occurrence of each value is kept, in its original order.

Is my data uploaded to a server?

No. The conversion runs entirely in your browser. Nothing you paste is sent or stored anywhere.

Can I use another separator than a comma?

Yes. Choose semicolon, pipe, space or new line. This is handy for CSV files, URLs, tags or config files.
